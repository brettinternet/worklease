Make tagged release and CI execution reproducible and reduce workflow supply-chain exposure. Pin release-critical Python build tools in the committed uv lock, pin every third-party GitHub Action to an immutable commit SHA with a readable version comment, and limit release write permission to the publishing job.

## Acceptance criteria

- [x] Hatchling and PyInstaller resolve from committed exact pins in uv.lock, and CI/release native builds do not use an unpinned --with dependency.

- [x] Workflow-level permissions are read-only and only the release publishing job receives contents: write.
- [x] Locked sync, tests, lint, formatting, typecheck, build, workflow validation, and frozen executable smoke checks pass.
