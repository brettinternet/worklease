# Provider References

Load only the reference matching each caller-resolved provider kind. These
references define provider deltas; [`contract.md`](../contract.md) remains
normative.

- [`backlog-md.md`](backlog-md.md) covers Backlog.md projects and tasks.
- [`loose-markdown.md`](loose-markdown.md) covers established Markdown work sources.
- [`github-issues.md`](github-issues.md) covers GitHub issue collections.
- [`linear.md`](linear.md) covers Linear teams, projects, and issues.
- [`jira.md`](jira.md) covers Jira sites, projects, and issues.
- [`unknown.md`](unknown.md) covers custom or unsupported provider kinds.

A provider reference is not authorization. The caller supplies credentials, allowed operations, exact source scope, and any provider-specific status/dependency interpretation.
